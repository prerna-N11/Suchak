# Suchak
Distributed sensor network and local gateway system for zone wise flood monitoring.

suchak is a flood monitoring with sensor like rain guage , vibration ,water level and camera it is designed to collect environmental data by these sensor nodes and transmit this all information to locall gateway for zone wise monitoring and early warning. 

## overview 
flash flood is a very crucial problem in today's time it become more important as it is very fast as compare to normal flood so we need a early warning system ,here we have suchak especially in area near rivers on above hill area and it will moniter the river level and rain to collect data from different zones location .
The system consists of sensor nodes deployed across different zones. these collect relevant environmental measurements and communicate the data to a local gateway .The gateway can then process, store , or forward the collected information for monitoring and further analysis .

## objectives 
- flash-flood sign can be caught before the water arrives.
- Monitor flood-related environmental conditions in different zones.
- Collect data from multiple distributed sensor nodes.
- confirmed risk is passed on to the next zone 
- Transmit sensor data to a local gateway.
- Enable zone-wise monitoring.
- works without internet.
- sirens fire only when signal agree. 
- authorities can act on what is happening in each zone based on data shown on their dashboard.
 Rainfall+Level+Vibration+Camer---> Rate of Rise --->Local Risk --->Downstream Warning--->Local Action
